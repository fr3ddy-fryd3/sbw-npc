# План: NPC-отряды для SuperbWarfare (NeoForge 1.21.1)

Статус: ✅ сделано · 🚧 сделано, но не подтверждено в игре / есть открытый пункт · ⬜ не начато

## Этап 0 — Фундамент аддона ✅

- Gradle-модуль на NeoForge 1.21.1, Java 21, Kotlin.
- Зависимость от SuperbWarfare через `includeBuild` composite build против локального
  снапшота (папка `./SuperbWarfare`, не в git) — нужны внутренние API мода, которых нет
  в опубликованном джарнике.
- Базовые реестры: `ModEntities`, `ModItems`, точка входа `SquadMod`.

## Этап 1 — NPC-сущность и визуал ✅

- `NpcEntity : PathfinderMob`. Не деспавнится при уходе игрока.
- Модель — ванильный `HumanoidModel`/`HumanoidMobRenderer` (`NpcModel`/`NpcRenderer`):
  держание оружия, позы рук (`PoseTool`), броня, ванильные анимации.
- 8 скинов по фракциям (см. «Фракции» ниже).
- Роль = класс + ранг (`NpcClass`, `NpcRank`), data-driven.

## Этап 2 — Боевой AI ✅

- Стрельба/прицеливание/перезарядка/режимы огня, ближний бой при нехватке патронов,
  укрытия/подавление/окапывание, слух/тревога отряда — все поведения на
  `SmartBrainLib` (`entity/ai/*Behaviour.kt`), детали — Этап 7.
- Свой/чужой по фракции (`SquadTeams.isHostile`).

## Этап 3 — Отряды, приказы, инструмент ✅

Мультитул: один предмет, два режима (Shift+ПКМ по воздуху переключает).

- **Recruit-режим**: ПКМ по воздуху — GUI выбора класса/ранга/фракции/пресета отряда
  (`SquadPreset`: SINGLE/FOUR/SIX/EIGHT/SIXTEEN/MORTAR_CREW); ПКМ по блоку — деплой.
- **Command-режим**: выделение отряда (клик по NPC, Shift — сброс), приказы
  ATTACK/DEFEND/PATROL/FREE, точка-objective, focus-цель (в т.ч. через HUD, см. Этап 5).
- `SquadManager : SavedData` — персистентные отряды (id, фракция, состав, приказ,
  objective, focus). Смерть NPC выводит его из отряда, пустые отряды удаляются.
- Переименование отряда.
- Точка сбора — казарма (`BarracksBlock`, разрушается киркой/взрывом), периодически
  досоздаёт погибших членов отряда.
- Патруль — маршрут из точек (`RouteManager`, вьюха Routes в Command GUI) либо, без
  маршрута, случайное блуждание в радиусе.

## Этап 4 — Миномёт и гранаты ✅

- `GRENADIER`: M79 + докидывание ручной гранаты на дистанции 5-16 блоков.
- `MORTAR_OPERATOR`: находит ближайший незанятый `MortarEntity` (радиус 30 блоков),
  наводится и стреляет. Цель — фокус/точка отряда при приказе ATTACK, иначе — автономный
  скан по радиусу обнаружения (80-160 блоков по рангу) или релей осведомлённости
  фракции. Не стреляет, если решение недостижимо (дальность/угол) или рядом свои.
  Разброс попадания — по рангу (5-10 блоков). Кулдаун выстрела — 50 тиков.
- `MORTAR_LOADER`: держит миномёт заряженным (1 снаряд в казённике), отдельный от
  оператора реестр занятости поста.
- Классовые множители дальности/точности (`NpcClass`) поверх базовой дистанции/спреда
  ранга.

## Этап 5 — Быстрое командование (HUD) ✅

- Клавиша `B` — небольшая неблокирующая HUD-панель (WASD/обзор продолжают работать).
- Клавиши 1-9 — сначала список отрядов, затем (тем же диапазоном) список приказов;
  выбор приказа сразу ставит и `order`, и `objective` по текущему направлению взгляда.
- Клавиша `0` — приказ сразу всем отрядам игрока его фракции.
- Перехват ванильного хотбара 1-9 на время открытой панели — через Mixin
  (`KeyMappingMixin`), тот же паттерн, что уже использует сам SuperbWarfare.
- Маркер точки-objective — частицы цвета фракции, видны только владельцу отряда.
- Список отрядов в HUD обновляется после каждого действия, не только при открытии.

## Мультиплеер: права владения 🚧

- Проверка владения отрядом на сервере: команды DISBAND/SET_ORDER/RENAME/SELECT/
  ARM_OBJECTIVE/ARM_FOCUS (в т.ч. из HUD) и клик по чужому NPC в Command-режиме требуют
  `squad.owner == отправитель`, иначе actionbar «Not your squad».
- ⬜ Не закрыто: НПС до формирования отряда не хранит, кто его задеплоил — в узком окне
  между деплоем и формированием отряда любой игрок технически может забрать его себе.
- ⬜ Отложено осознанно: фракция отряда сейчас общая на сервер (не привязана к
  игроку) — два игрока с одинаковой фракцией автоматически станут союзниками. Задуман
  (не реализован) дефолт «своей» фракции на игрока + админ-команда для выдачи права на
  любую фракцию.

## Фракции (скины и команды) ✅

- `SquadFaction` — 8 фракций (Piggies/Cows/Creeps/Sheep/Pandas/Cats/Enders/Withers),
  каждая — `label`, `texture`, `accentColor`.
- `SquadTeams` ключуется по фракции (vanilla-команда `sbwnpc_<фракция>`); свой/чужой,
  рендер скина — через неё.
- Броня по фракциям (Этап 8): зелёный комплект (RU) или песочный (US).

## Этап 6 — Тактика и логистика ✅

- Обязательный (один раз) экран выбора фракции при первом взаимодействии с
  тулом — фиксирует дефолт на будущее; свободный выбор любой фракции на
  деплое/в Recruit GUI по-прежнему доступен (осознанно, на время разработки).
- ИИ не стреляет по своим на линии огня — конус разброса выстрела + отдельная
  проверка блaст-радиуса взрывного оружия, пересчёт каждый тик (`FriendlyFireGuard`).
- Казарма-блок и деплой из тула: точка возрождения/деплоя всегда проверяется на
  свободность места (`SafeSpawn`) с несколькими попытками смещения и гарантированным
  fallback на исходную (заведомо стоящую на земле) точку.
- Waypoints (вьюха маршрутов, режим записи точек).

## Этап 7 — SmartBrainLib + тактика ✅

Полная миграция `NpcEntity` с `Goal`/`GoalSelector` на `SmartBrainLib` (Brain-поведения).
`registerGoals()` теперь содержит только 3 тривиальных ванильных goal'а (плавание,
взгляд, блуждание — оба последних дополнительно проверяют `target`/`diggedIn`, чтобы не
конфликтовать с боем/окапыванием). Всё остальное (двери, выбор цели, стрельба, ближний
бой, гранаты, миномёт, укрытия/подавление/окапывание, тревога/расследование, построения/
патруль) — в `entity/ai/*Behaviour.kt`.

- Построения отряда (`SquadFormation`): клин на ATTACK, линия на DEFEND, колонна на
  PATROL, кольцо/рассеянный периметр по достижении позиции — свой слот-офсет на
  каждого члена, а не общая точка.
- Поиск укрытия: сеточный скан к стенам/впадинам местности + случайные сэмплы, точка
  должна быть скрыта от ВСЕХ известных врагов рядом (не только от того, кто подавил).
- Окапывание — последний рубеж, если укрытия нет: НПС роет себе яму, если ранен ниже
  25% здоровья, рядом реально прикрывает союзник, земля под ногами диггабельна (грунт
  или песок) и ровная со всех сторон. Держит позицию (стреляет из ямы, не выглядывая),
  пока не подлечится выше того же порога или подавление не спадёт само; при повторном
  попадании может докопать ещё один (не более) блок вглубь. По здоровью выше порога, но
  без укрытия рядом — держит текущую позицию стрельбы вместо бегства. Выход из ямы после
  лечения гарантирован (пробивает стену и телепортируется наружу, если не может выйти
  обычным путём).
- Тревога/расследование: осведомлённость фракции о замеченных врагах (с задержкой
  ретрансляции), слуховая тревога от выстрелов и смертей союзников.

## Этап 8 — Разнообразие снаряжения, медик ✅

- Броня по фракциям — см. «Фракции» выше.
- Оружие: 2 варианта на категорию (пистолет/ПП/автомат/пулемёт/снайперка), случайный
  выбор на каждого НПС при спавне — визуальное разнообразие внутри класса.
- Новый класс `MEDIC`: ПП, лечит раненых союзников своей фракции (не только своего
  отряда) — критических (ниже 30% HP) даже под огнём, остальных — когда сам не в бою.
  Обычная скорость как у снайпера, во время бега лечить — быстрее.
- `GRENADIER` убран из отрядных пресетов (8/16 теперь с `MEDIC`), доступен только через
  ручной Single-спавн.
- Скорость передвижения — по классу (медик/снайпер/пулемётчик/гренадир быстрее или
  медленнее базового), не единая на всех.
- Позиция с частичным укрытием тела во время активного боя
  (`GunAttackBehaviour.holdFiringPosition`): заняв дистанцию стрельбы, НПС ищет рядом
  (7 блоков) точку, скрывающую как можно больше тела при сохранении возможности
  стрелять, и держит её несколько секунд перед следующей перебежкой/переоценкой.
- Debug-частицы (выбор укрытия, выбор позиции стрельбы) — за одним флагом
  `DebugFlags.MARKERS_ENABLED`.

## Этап 9 — Техника и дроны ⬜

- Менеджмент-тул: наведение на технику/дрон → присвоение фракции отряда.
- Friend/foe для автономной техники (`TowerAI.TeamResolver`).
- Визуальная индикация фракции на технике.
- НПС физически управляют техникой (не только красят) — вход через `startRiding`
  в обход игрового `interact`, управление через синхронизируемые input-флаги
  (`VehicleEntity`/`VehicleEngineUtils`) той же техникой, что и игрок.

## Этап 10 — Получение NPC ⬜

- Основной способ найма — режим «Вербовка» тула (см. Этап 3).

## Этап 11 — Полировка ⬜

- Лут с убитых NPC (оружие/патроны/броня).
- Барки/озвучка (вижу цель, перезарядка, отступление).
- Анимация отдачи при выстреле.
- Балансировка через конфиги (Cloth Config).
